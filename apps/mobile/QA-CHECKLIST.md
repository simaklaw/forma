# QA-CHECKLIST: что проверить руками на устройстве

Ни `tsc`, ни `eslint`, ни `jest` не запускают приложение — они проверяют
типы/стиль/чистые функции. Ничего из списка ниже не проверено в среде, где
велась разработка (нет Metro/симулятора/устройства — см. HANDOFF.md).
Прогнать разово после `npm install && npx expo start` на реальном
Android-устройстве, до того как полагаться на "CI зелёный" как на
доказательство, что приложение реально работает.

## Критичное (баги, которые чинились вслепую — нужно физическое подтверждение)

- [ ] **Таймер отдыха переживает блокировку экрана.** Начать подход,
      дождаться экрана отдыха, заблокировать телефон на 90+ секунд, вернуться.
      Ожидается: оставшееся время — честное (не зависшее, не убежавшее
      вперёд), звук/haptic «отдых закончен» срабатывает сразу по возврату,
      если время уже вышло, а не через ещё один полный цикл `setInterval`.
- [ ] **Звук `beep.wav` слышен** в конце отдыха (не только haptic).
- [ ] Жесты `@gorhom/bottom-sheet` — открытие/закрытие свайпом, не только
      тапом, на всех трёх экранах упражнений.

## Сеть (единственный живой вызов в проекте)

- [ ] Фото техники из wger подгружается в `ExerciseSheet` для всех трёх
      упражнений (`wgerSearchTerm`: Barbell Squat / Deadlift / Dumbbell
      Lunge) — и повторно открывается мгновенно из кэша при второй попытке
      в течение недели (см. `useExerciseReference.ts`, TTL 7 дней).
- [ ] Отключить интернет — экран не падает и не виснет, просто без фото.

## Персистентность / бэкап

- [ ] Записать несколько подходов, приёмов пищи, обновить вес — закрыть
      приложение полностью (не свернуть) — открыть заново — всё на месте.
- [ ] Экспорт бэкапа (`ProfileScreen` → «Экспорт данных») → шэринг/сохранение
      файла реально работает.
- [ ] Импорт того же файла на чистой установке восстанавливает профиль,
      вес, подходы, приёмы пищи и рекорды (`personalRecords` — новое поле,
      не проверялось на реальном импорте).
- [ ] Импорт заведомо битого JSON — приложение показывает `Alert` с
      понятной ошибкой, а не падает.

## Общее ощущение

- [ ] Haptics (Light при переключении вкладок, Heavy при подходе, Success
      при завершении дня) — реально ощущаются, не только не падают.
- [ ] Тёмная протокольная тема читается на реальной Android-яркости экрана
      (не только на превью в браузере/симуляторе).
- [ ] Реакция на `TalkBack`/увеличенный системный шрифт хотя бы бегло — не
      проверялось вообще ни разу за весь проект.
