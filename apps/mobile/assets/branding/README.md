# FitPulse brand assets

These assets are the extracted, transparent logo variants from the supplied FitPulse brand sheet. The source collage is not bundled into the application.

| File | Use |
|---|---|
| `fitpulse-icon.png` | Expo primary app icon with the dark brand background |
| `fitpulse-adaptive-foreground.png` | Android adaptive icon foreground; transparent canvas |
| `fitpulse-splash-icon.png` | Expo splash mark on the dark background |
| `fitpulse-mark.png` | Reusable square F/pulse mark |
| `fitpulse-wordmark.png` | Horizontal FitPulse wordmark for future in-app branding |

The app configuration references the icon, adaptive foreground, and splash assets from `apps/mobile/app.json`.
