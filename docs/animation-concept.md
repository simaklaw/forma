# Идеальная 3D-анимация для exercise каталогов (forma)

Проверенно: симакlaw/fitpulse-godot-animation-studio PR #20 (merged).

## Требования к биомеханике (строго)
- Линия тела прямая: макушка → плечи → бёдра → пятки.
- Ягодицы не подниматься выше линии спины (исправлено относительно текущих артефактов).
- Угол локтя при сгибе: 25°–75° (текущие значения ~23.3°/24.8° — требуют пересчёта в patch_opengym3d_pushup.py).
- Контакт ладоней/стоп с полом непрерывен.
- Цикл 3.2 с @ 30 fps без пропуска поз.

## Визуальный стандарт (стиль forma)
- Персонажи: стилизованные 3D (не реалистичные), чёткие формы.
- Одежда: минимализм — обтягивающие топы/шорты нейтральных цветов (серый, чёрный, бирюзовый), без логотипов.
- Освещение: мягкое, акцент на контуры тела, тёмный фон для контраста.
- Прозрачный фон (RGBA) для интеграции в Godot / форма.

## Почему текущие артефакты не подходят
- Poster male/female показывают поднятые ягодицы (нарушение техники).
- Реалистичная одежда с деталями не соответствует минимализму.
- Волосы (рыжие женские) требуют пересмотра цветовой палитры (отсутствие мадженты — верно, но стиль не подходит).
