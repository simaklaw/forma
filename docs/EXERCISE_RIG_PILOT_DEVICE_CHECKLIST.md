# Проверка пилотной 2D-анимации FitPulse на Android

Эта проверка нужна перед расширением рига на всю библиотеку. Пилотный APK — тестовый, его не следует считать релизной сборкой.

## Где взять тестовую сборку

1. Открой [Build Android APK — актуальная preview run](https://github.com/simaklaw/forma/actions/runs/39131576137).
2. Дождись статуса **Success**.
3. Внизу страницы открой **Artifacts** → `fitpulse-android-standalone-apk` → скачай ZIP и распакуй его на телефоне.
4. Установи APK, разрешив установку из выбранного источника, если Android спросит.

Ожидаемая ревизия APK: `434ab909908768338e903bf704727f291e658ceb` (короткий SHA `434ab90`). Этот preview собран после последней правки геометрии отжиманий. SHA относится к одноразовому commit запуска сборки; после старта workflow-триггер возвращён в ручной режим. Сам код анимации совпадает с текущей веткой.
5. На экране «О приложении» проверь SHA/версию сборки. Это пробная ветка анимаций, а не `main`.

Если загрузка или установка не удалась — зафиксируй текст ошибки/скриншот и не удаляй текущую рабочую версию FitPulse.

## Проверка пилота (3 упражнения)

Открой упражнение сначала в каталоге, затем в экране активной тренировки:

- Домашний ID `10`: **Отжимания**.
- Домашний ID `13`: **Приседания**.
- Зал ID `5`: **Жим гантелей сидя** (вариант из текущего плана зала).

Для каждого движения проверь:
- персонаж виден целиком, суставы не скачут, кисти/стопы не оторваны от тела;
- движение легко узнать по исходной и конечной позиции; оборудование находится в руках/поддерживает тело;
- нет чёрных/пустых кадров, наложения текста на персонажа или обрезания конечностей;
- анимация останавливается, когда карточка скрыта/закрыта, и продолжает работать при повторном открытии.

## Профиль и темы

1. В профиле выбери мужчину и открой все три упражнения: должен показываться мужской персонаж.
2. Поменяй профиль на женщину и открой эти же движения: должен показываться женский персонаж.
3. Проверь светлую и тёмную тему; фон, персонаж и акценты должны сохранять хороший контраст.
4. Включи авиарежим и повторно открой три движения. Пилотные SVG-анимации должны работать без сети.

## Решение после проверки

Отметь один результат:
- **OK** — все три упражнения читаемы в обоих профилях и обеих темах, офлайн тоже работает;
- **Needs polish** — работает, но нужны правки внешности/поз/тайминга;
- **Blocker** — неправильное движение, пустой экран, сбой или проблемы производительности.

До проверки на телефоне и устранения замечаний PR остаётся Draft. `main` не изменяется.
