# Smoke-сборки APK для проверки на устройстве

Процесс закрытия обратной связи «фикс в коде → APK на телефоне»:

1. Кодовые фиксы мержатся в `main` через PR (Monorepo CI зелёный).
2. От свежего `main` создаётся ветка `build/android-smoke-<N>` и в неё пушится
   любой коммит (например, правка этого файла) — создание ветки без коммита
   push-событие не вызывает.
3. Push в `build/android-smoke-*` запускает `build-apk-smoke.yml`, который через
   `workflow_call` вызывает основной `build-apk.yml` (~28 мин).
4. Готовый артефакт `fitpulse-android-standalone-apk` забирается из
   Actions → «Build Android APK (smoke branch)» и устанавливается на устройство.
5. Владелец проходит чек-лист устройства (EXERCISE_RIG_PILOT_DEVICE_CHECKLIST.md
   + чек-лист в PR фикса); ветка smoke по итогам удаляется.

История smoke-веток: `build/android-smoke` (#173), `-2` (#176), `-3` (#177), `-4` (PR #304:
клетки воды, секундный таймер голодания, режим «Зал» в каталоге, edge-to-edge шторка
справочника, + весь контент #303: таймер подхода, 4 упражнения зала 63–66, чип оборудования).
